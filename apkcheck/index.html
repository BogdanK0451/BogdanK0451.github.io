Pure-Python script that inspects an Android APK without running anything from it

No pictures on this roll. The project is described below.

A small read-only APK inspector written to vet a downloaded Android app before installing it. It parses the binary AndroidManifest.xml, reads the v2/v3 signing block and decodes the signing certificates by hand, then lists permissions and components and scans the DEX files for suspicious strings. It uses only the Python standard library.

Highlights

  • Hand-written binary XML (AXML) parser for the compiled manifest
  • APK Signature Scheme v2/v3 block reader with a minimal DER/X.509 decoder
  • Lists permissions, components and risky flags (debuggable, cleartext traffic, backup)
  • DEX string probes to look for injected or unexpected code
