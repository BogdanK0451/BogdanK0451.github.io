Bookmark cleanup

15A · TOOL · OCT 2026

Single-page tool for triaging a large browser bookmarks export into keep and remove

No pictures on this roll. The project is described below.

A self-contained HTML page made to clean up years of browser bookmarks. It groups the bookmarks, suggests which to keep or remove, and lets you accept or override the suggestions in bulk. It then downloads a clean bookmarks file to import back into the browser, plus an archive of everything removed.

Highlights

  • Grouped review with keep/remove suggestions and bulk keep or remove of everything shown
  • Exports a browser-importable bookmarks file and a separate archive of the removed ones
  • Runs offline from one file; nothing leaves the machine
